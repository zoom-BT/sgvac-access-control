# Images SGVAC — à déposer ici

Place tes photos réelles dans ce dossier. L'app les utilisera automatiquement si présentes.

| Fichier | Usage | Recommandation |
|---------|-------|----------------|
| `chantier-bg.jpg` | Fond global (login, dashboard) | Photo chantier BTP : grue, béton, ouvriers (paysage 1920×1080 min) |
| `portail-bg.jpg` | Fond écran poste de contrôle `/access` | Photo portail d'entrée chantier, barrière, cabine garde |
| `texture-overlay.png` | Texture légère par-dessus (optionnel) | Overlay béton/grain semi-transparent |

Formats acceptés : `.jpg`, `.jpeg`, `.webp`, `.png`

Si une image manque, un dégradé industriel s'affiche à la place.
